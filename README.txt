Hyloveclub - Taiwan 16-Tile Mahjong / 海納福台灣十六張麻將 v5
=============================================================
File: index.html (single-file GitHub Pages site; no external assets required).

NEW in v5
- Mahjong tile faces use high-contrast scalable vector symbols rather than plain text.
  Characters: large red 1–9 and suit mark.
  Bamboos: bird for 1; countable bamboo sticks and special 8 pattern.
  Dots: numbered circle patterns.
  Winds: E→ S↓ W← N↑, matching the approved reference.
  Dragons: 中 + red dragon, 發 + green dragon, outlined white dragon.
  Flowers and Seasons: small Chinese characters and icons.
- Traditional Chinese / English toggle (language preserved on this browser).
- Bilingual in-game how-to-play, scoring and a tile legend.
- Retains v4 one-player/three-computer game, hint, score calculation,
  discard-win single-payer payment and self-draw three-payer payment.
- Desktop single-screen layout and touch-friendly mobile layout.

Deployment: create/update a GitHub Pages repository; upload index.html to
its root directory, then enable Settings > Pages > Deploy from branch > main /(root).
Example proposed repository: taiwan-16-mahjong.

Important: This is a simplified practice game. House rules vary; flower tai,
consecutive-dealer bonuses and certain special winning hands are not included.
